# 重启后服务启动指南

适用场景：

- 电脑重启后，需要尽快恢复当前项目的本地开发环境
- 需要继续使用：
  - 管理后台
  - 本地后端
  - 微信小程序真机扫码预览

当前固定域名链路为：

```text
小程序 -> https://api.fulian520.com/api/v1
       -> Cloudflare Tunnel
       -> 本地 FastAPI :8000
```

---

## 一、最常用的恢复顺序

建议每次开机后按这个顺序启动：

1. 启动本地后端
2. 启动 Cloudflare Tunnel
3. 启动管理员后台（如果需要）
4. 打开微信开发者工具（如果需要小程序）

---

## 二、场景 A：只恢复小程序手机扫码预览

如果你当前只想让手机扫码的小程序继续可用，只需要恢复下面两项：

### 1. 启动后端

```powershell
cd "D:\website project\backend"
powershell -ExecutionPolicy Bypass -File .\scripts\start_backend_server.ps1
```

等它启动后，验证：

```text
http://127.0.0.1:8000/health
```

预期返回：

```json
{"status":"ok"}
```

### 2. 启动固定域名 Tunnel

新开一个 PowerShell 窗口，执行：

```powershell
cd "D:\website project\backend"
powershell -ExecutionPolicy Bypass -File .\scripts\start_backend_cloudflare_tunnel.ps1
```

cloudflared tunnel run fulian-backend

这个窗口不要关闭。

然后验证：

```text
https://api.fulian520.com/health
```

预期返回：

```json
{"status":"ok"}
```

如果这两个地址都正常，小程序真机预览就有条件恢复。

## 三、场景 B：恢复管理后台 + 小程序

如果你要同时做后台管理和小程序预览，按这个顺序：

### 1. 启动后端

```powershell
cd "D:\website project\backend"
powershell -ExecutionPolicy Bypass -File .\scripts\start_backend_server.ps1
```

### 2. 启动 Cloudflare Tunnel

```powershell
cd "D:\website project\backend"
powershell -ExecutionPolicy Bypass -File .\scripts\start_backend_cloudflare_tunnel.ps1
```

### 3. 启动管理后台

新开一个 PowerShell 窗口：

```powershell
cd "D:\website project\frontend"
npm.cmd run dev -- --host 127.0.0.1
```

访问：

```text
http://127.0.0.1:5173/
```

### 4. 如需 H5 小程序预览

如果你还要看 miniapp 的 H5 调试版本，再开一个窗口：

```powershell
cd "D:\website project\miniapp"
npm.cmd run dev:h5
```

访问：

```text
http://127.0.0.1:5175/
```

## 四、场景 C：重新生成微信小程序预览包

如果你修改了 miniapp 代码，重启后除了启动服务，还需要重新构建小程序包：

```powershell
cd "D:\website project\miniapp"
npm.cmd run build:mp-weixin
```

然后在微信开发者工具中：

1. 打开项目
2. 重新编译
3. 如有需要，重新生成“预览”二维码

当前导入目录：

```text
D:\website project\miniapp\dist\build\mp-weixin
```

## 五、启动后快速检查清单

每次恢复后，按下面顺序检查最省时间：

### 1. 后端检查

打开：

```text
http://127.0.0.1:8000/health
```

### 2. 固定域名检查

打开：

```text
https://api.fulian520.com/health
```

### 3. 管理后台检查

打开：

```text
http://127.0.0.1:5173/
```

### 4. 小程序接口检查

如果微信小程序里功能点击后仍报网络错误，优先检查：

- 后端窗口是否还在运行
- Tunnel 窗口是否还在运行
- 微信开发者工具是不是旧包
- 手机上扫的是不是新的预览码

## 六、每个窗口分别做什么

建议你以后固定保留这 3 到 4 个窗口：

### 窗口 1：后端服务

运行：

```powershell
cd "D:\website project\backend"
powershell -ExecutionPolicy Bypass -File .\scripts\start_backend_server.ps1
```

用途：

- FastAPI 后端
- 所有前端 / 小程序接口都依赖它

### 窗口 2：Cloudflare Tunnel

运行：

```powershell
cd "D:\website project\backend"
powershell -ExecutionPolicy Bypass -File .\scripts\start_backend_cloudflare_tunnel.ps1
```

用途：

- 把 `api.fulian520.com` 转到你本地 `8000`
- 小程序真机扫码依赖它

### 窗口 3：管理员后台

运行：

```powershell
cd "D:\website project\frontend"
npm.cmd run dev -- --host 127.0.0.1
```

用途：

- 后台录入新闻、公告、开票处理、导入数据

### 窗口 4：miniapp H5 调试（可选）

运行：

```powershell
cd "D:\website project\miniapp"
npm.cmd run dev:h5
```

用途：

- 浏览器里调试小程序界面

## 七点五、一键总启动脚本

如果你不想每次手动开多个窗口，现在可以直接使用总启动脚本：

- [scripts/start_all_services.ps1](D:/website%20project/scripts/start_all_services.ps1)

### 默认启动

默认会启动：

1. 本地后端
2. Cloudflare Tunnel
3. 管理后台

运行命令：

```powershell
cd "D:\website project"
powershell -ExecutionPolicy Bypass -File .\scripts\start_all_services.ps1
```

### 连 miniapp H5 一起启动

```powershell
cd "D:\website project"
powershell -ExecutionPolicy Bypass -File .\scripts\start_all_services.ps1 -IncludeMiniappH5
```

### 启动时顺手重新构建微信小程序包

```powershell
cd "D:\website project"
powershell -ExecutionPolicy Bypass -File .\scripts\start_all_services.ps1 -RebuildMiniapp
```

### 全都做

```powershell
cd "D:\website project"
powershell -ExecutionPolicy Bypass -File .\scripts\start_all_services.ps1 -IncludeMiniappH5 -RebuildMiniapp
```

### 日志位置

脚本会把后台进程日志统一写到：

```text
D:\website project\.runtime\
```

例如：

- `backend.out.log`
- `backend.err.log`
- `cloudflare-tunnel.out.log`
- `frontend.out.log`
- `miniapp-h5.out.log`

## 八、常见问题

### 1. `https://api.fulian520.com/health` 打不开

优先检查：

1. 后端是否启动
2. Tunnel 是否启动
3. 电脑是否联网
4. Cloudflare Tunnel 窗口里是否有报错

### 2. 后台能打开，但小程序请求失败

通常是：

1. Tunnel 没开
2. 微信开发者工具还是旧编译包
3. 手机扫的是旧二维码

### 3. 为什么每次重启都要重新开 Tunnel

因为当前后端还跑在本地电脑上，不是云服务器。

只要：

- 电脑关机
- 电脑休眠
- Tunnel 进程退出

外部通过 `api.fulian520.com` 的访问就会中断。
