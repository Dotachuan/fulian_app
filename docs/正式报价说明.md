# 福莲教育促进会项目正式报价说明

更新时间：2026-05-07

## 一、项目概述

本项目为福莲教育促进会的信息化定制项目，当前建设内容涵盖：

- 管理后台
- 用户端小程序
- 后端业务接口与数据库
- 捐赠数据管理与导入
- 会员体系与身份识别
- 开票申请与后台处理
- 新闻、公告、产业园、公益项目等内容管理与展示

项目并非模板式搭建，而是基于实际业务场景进行的定制开发，涉及前端界面设计、后端业务逻辑、数据库结构、管理后台能力、小程序真机适配及后续上线准备。

## 二、当前建设范围

截至当前版本，项目已包含或正在交付的主要能力如下：

### 1. 管理后台

- 管理员登录与基础权限控制
- 捐赠人、捐赠记录、基金、基金收支管理
- 开票申请查看、处理、批量处理、导出
- 新闻推文管理
- 公告管理
- 产业园链接管理
- 公益项目链接管理
- 会员管理与会员资料维护
- 图片上传并自动生成可访问地址
- Excel 捐赠数据预分析与批量导入

### 2. 小程序端

- 首页展示
- 新闻模块
- 活动模块
- 公告模块
- 关于福莲模块
- 福莲产业园模块
- 公益项目进展模块
- 会员通讯录
- 我的页面与会员资料补录
- 捐赠查询与捐赠证书
- 开票申请
- 会员登录与身份识别

### 3. 后端与数据能力

- FastAPI 后端接口开发
- MySQL 数据结构设计与维护
- 会员身份自动计算逻辑
- 小程序与后台共用业务接口
- 静态资源与上传图片访问能力
- 域名、本地联调、真机预览链路打通

## 三、项目特征说明

本项目属于中等偏复杂的定制系统，不属于普通展示型小程序。主要复杂度体现在：

- 同时包含后台、后端、小程序三端
- 存在会员、捐赠、基金、开票等真实业务逻辑
- 存在批量导入、数据清洗、自动归类与统计能力
- 存在持续迭代与需求变更
- 需要兼顾小程序真机体验与后台可运营能力

## 七、后续新增需求说明

若后续继续新增功能，建议按以下方式执行：

### 1. 小幅调整

如：

- 文案调整
- 轻量样式优化
- 小范围字段增减
- 非核心流程的小修正

可按维护工时或打包小版本方式处理。

### 2. 中等新增模块

如：

- 新的内容管理模块

- 新的查询或统计能力
- 新的小程序页面与后台页面联动

建议单独评估并补充报价。

### 3. 上线与运维相关

如：

- 服务器部署
- 数据迁移
- 正式环境配置
- 微信发布协助

建议单列为部署服务或上线支持费用。
