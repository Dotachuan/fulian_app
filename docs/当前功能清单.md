# 当前功能清单

更新时间：2026-05-03

## 1. 项目概况

当前项目是一个基金会捐赠管理系统，包含三部分：

```text
backend/   后端 API（FastAPI + SQLAlchemy + MySQL）
frontend/  管理员后台（Vue 3 + Vite + Element Plus）
portal/    用户端前台（Vue 3 + Vite + Element Plus）
```

当前本地访问地址：

```text
管理员后台：http://127.0.0.1:5173/
用户端前台：http://127.0.0.1:5174/
后端接口：http://127.0.0.1:8000/
健康检查：http://127.0.0.1:8000/health
Swagger：http://127.0.0.1:8000/docs
```

默认管理员账号：

```text
admin / Admin@123
```

## 5. 数据导入与历史数据处理能力

### 5.1 donate.xls 识别与转换

已实现：

- 识别项目根目录下的 `donate.xls`
- 读取 2020 年到 2026 年工作表
- 将“理事 + 年份 + 非零项目金额”转换为标准化捐赠记录
- 输出标准化 JSON

当前主要转换结果：

```text
Donors: 409
Targets: 22
Donations: 993
Total amount: 29831268.92
Warnings: 35
```

### 5.2 历史导入数据同步到基金收入

已实现：

- 将历史导入的捐赠记录同步为基金收入流水
- 自动补齐基金收入记录

当前同步结果：

```text
Imported donation records scanned: 993
Funds created: 22
Fund income records created: 993
Skipped records: 0
```
