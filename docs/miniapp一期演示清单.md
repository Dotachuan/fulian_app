# miniapp 一期演示清单

更新时间：2026-05-04

## 1. 演示目标

本清单用于验证 miniapp 一期“会员核心闭环”是否稳定可演示。

当前重点链路：

1. 会员登录
2. 首页会员态变化
3. 我的捐赠
4. 捐赠证书
5. 开票申请
6. 后台查看开票申请
7. 会员名录
8. 财务公示

## 2. 准备条件

启动地址：

```text
后端：http://127.0.0.1:8000/
管理后台：http://127.0.0.1:5173/
miniapp H5：http://127.0.0.1:5175/
```

演示前确认：

1. 后端服务已启动
2. 管理后台可正常登录
3. miniapp H5 页面可正常打开
4. 后台存在至少 1 个已绑定 donor 的会员手机号
5. 后台存在至少 1 个未绑定 donor 的会员手机号
6. 如需演示“重复待处理”，准备 1 个重复手机号会员

## 3. 演示路径

### 场景 A：已绑定会员

1. 打开 miniapp 首页
2. 使用已绑定手机号登录
3. 登录成功后返回首页
4. 检查首页首屏状态：
   - 显示会员态
   - 主按钮为“查看我的捐赠”
   - 显示绑定状态
5. 进入“我的捐赠”
6. 检查：
   - 累计金额
   - 累计笔数
   - 捐赠明细
   - 加入福莲第 X 年
7. 进入“捐赠证书”
8. 检查：
   - 证书可生成
   - 可点击保存
9. 进入“开票申请”
10. 填写并提交一条申请
11. 登录后台，进入“开票申请管理”
12. 检查新申请是否出现在待处理列表

### 场景 B：未绑定会员

1. 使用未绑定 donor 的手机号登录
2. 返回首页
3. 检查首页状态文案是否提示待绑定
4. 进入“我的”
5. 检查会员状态说明是否清楚
6. 进入“我的捐赠”
7. 检查是否显示待绑定提示，而不是报错或空白
8. 进入“开票申请”
9. 检查页面可正常打开，并能展示当前会员状态说明

### 场景 C：重复手机号待处理

1. 使用重复手机号会员登录
2. 检查首页与“我的”页是否显示“待人工处理”
3. 进入“我的捐赠”
4. 检查是否阻止继续查看捐赠数据，并给出明确提示

## 4. 页面级检查项

### 首页

1. 未登录时主按钮为“会员登录”
2. 已登录且已绑定时主按钮为“查看我的捐赠”
3. 新闻与公告加载失败时不白屏
4. 公开栏目仍可正常访问

### 登录页

1. 手机号格式不完整时不能正常触发验证码获取
2. 倒计时状态正常
3. 登录成功后跳回首页
4. 开发环境验证码显示正常

### 我的捐赠

1. 已绑定时能看到汇总和明细
2. 未绑定时显示状态说明
3. 无数据时显示正式空状态

### 开票申请

1. 默认资料可保存
2. 提交时自动带出默认资料
3. 金额、日期格式校验正常
4. 提交成功后后台可见

### 会员名录

1. 未登录不可直接使用
2. 登录后可查看姓名与工作单位
3. 不展示电话

### 财务公示

1. 未登录不可直接使用
2. 登录后可查看基金列表
3. 可进入基金明细

## 5. 异常检查项

1. token 失效后再次访问受限接口，会清理登录态并回到登录页
2. 后端返回 422 时，页面会显示具体校验错误
3. 网络失败时，页面不会白屏
4. 待绑定和重复待处理状态不会继续请求需要 donor 绑定的接口
