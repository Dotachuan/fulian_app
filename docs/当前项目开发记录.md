## 7. 运行和构建注意事项

前端构建：

```powershell
cd "D:\website project\frontend"
npm.cmd run build
```

portal 构建：

```powershell
cd "D:\website project\portal"
npm.cmd run build
```

注意事项：

- `portal/node_modules` 是指向 `frontend/node_modules` 的 Junction，因为之前单独安装依赖网络超时。
- Vite/esbuild 在沙箱中可能出现 `EPERM`，必要时需要提升权限运行构建。
- 后端新增模型后需要重启后端服务。
- 项目目前不是 Git 仓库，不能依赖 `git status`。
- PowerShell 中读取中文有时显示乱码，但应用和 JSON 实际通常正常。
